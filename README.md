# TentaKlik

Website untuk TentaKlik, agensi digital marketing, dibangun dengan Astro dan di-deploy ke Cloudflare Workers.

## Fitur

- Halaman single-site: hero, layanan, studi kasus, harga, proses kerja, FAQ
- Animasi scroll halus (Lenis) dan custom cursor
- Marquee brand dan efek konfeti
- Styling Tailwind CSS

## Tech Stack

- Astro + TypeScript
- Tailwind CSS v4
- Cloudflare Workers (Wrangler), Bun untuk build

## Cara Menjalankan

```bash
bun install
bun run dev
```

Build dan deploy:

```bash
bun run deploy
```
